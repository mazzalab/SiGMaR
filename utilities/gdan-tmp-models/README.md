# utilities/gdan-tmp-models/

This folder is empty in the git repository on purpose.

It must contain the GDAN-TMP toolset (JADBio, SKGrid, AKLIMATE, SubSCOPE,
CloudForest) used by the **TMP** subtyping method — each model runs in its
own Docker container (see the main [README → Subtyping methods](../../README.md#subtyping-methods)).

This bundle is about 2.6 GB and is not kept in git. Download it from the
SiGMaR data/installer bundle on Zenodo and unpack it into this folder:
