# bin/

This folder is empty in the git repository on purpose.

It must contain the pre-built Docker images used by the macOS installer
(`setup.sh` loads them from here — see the main
[README → macOS installation](../README.md#macos)).

Download the images from the SiGMaR data/installer bundle on Zenodo and
place them in this folder before running `setup.sh`:
